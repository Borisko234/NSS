## Popis
Táto prehliadačová aplikácia umožňuje používateľom vytvárať zeleninové, kvetinové a ovocné záhrady. Používatelia môžu vytvoriť mriežku a následne vyčleniť sekcie mriežky pre každú rastlinu.

## Inštalácia
1. Klonujte tento repozitár na plochu.
2. Prejdite do hlavného adresára projektu.
3. Otvorte súbor `js/index.html` vo vašom webovom prehliadači.
